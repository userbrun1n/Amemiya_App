# 🚗 AMEMIYA App

Bem-vindo à melhor maneira de cuidar do seu veículo corporativo.  
Este é um aplicativo Android desenvolvido em **Kotlin** com **Jetpack Compose**, ainda em versão **beta**(!!!) criado para ajudar no controle da manutenção e abastecimento dos veículos da empresa Amemiya, além da localização em tempo real dos carros.

## ✨ Funcionalidades atuais

- Tela inicial com design moderno e inspirado na paleta de cores da Uber
- Fluxo de autenticação:
  - Cadastro (SignUp)
  - Login
  - Verificação de código (Verify)
  - Seleção de cidade
- Home com navegação para:
  - Perfil
  - Detalhes do carro
  - Histórico
  - Suporte
- Fluxo de manutenção:
  - Agendamento de manutenção
  - Geração de fatura
  - Confirmação de envio


## 🔮 Planos Futuros

- Integração com as tecnologias *LoRa* e *MQTT* para comunicação à longa distância e comunicação em tempo real entre o veículo e o aplicativo.
- Anexar dashboards online dentro do aplicativo
- Banco de Dados dos registros de abastecimento e manutenções realizadas

## 🚀 Como rodar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/amemiya-app.git
2. Entre na pasta:
  ```bash
   cd amemiya-app
```
3. Abra o arquivo no Android Studio:
    - Abra o Android Studio
    - Clique em File >>> Open
    - Selecione a pasta "amemiya-app"
    - Aguarde o *Gradle Sync* ser completado

4. Rodar o aplicativo:
   - No lado direito do programa, há um ícone de nome "*Running Devices*". Clique nesse ícone
   - Abrirá um celular virtual Android (talvez demore um tempo para poder usar)
   - Clique em "Run" e o app será aberto no dispositivo virtual.
   - Teste o app
